# 탁구센터

첨부된 탁구센터 기능 목록을 바탕으로 만든 센터 운영 웹앱입니다.

## 실행

Node.js 24 이상이 필요합니다. 외부 런타임 패키지를 설치할 필요가 없습니다.

```sh
npm start
```

기본 포트는 3000입니다. `PORT`로 변경할 수 있습니다. SQLite 데이터는 `data/center.sqlite`에 저장됩니다. `DATA_DIR`로 별도 저장 위치를 지정할 수 있습니다. 백업할 때는 서버를 중지한 뒤 데이터 디렉터리를 복사하세요.

## 기능

- 회원 정보: 연락처, 생년월일, 성별, 등록일, 회원 유형, 제주협회 선수 등록, 부수, 심판 자격
- 회비: 연·월회비, 레슨비, 참가비, 행사비, 물품비, 후원금 및 납부 상태
- 레슨: 담당 코치, 월 횟수, 시간, 시작일, 단계, 완료·보충 횟수, 모집 가능 인원
- 대회·행사: 일시, 장소, 참가자격, 대상인원
- 소통: 공지와 회원 메시지 게시 및 조회 (실시간 채팅·카카오톡 연동 아님)
- 영업: 영업시간, 휴무일, 구장 이용료
- 정산: 관련 대회, 총액, 후원금, 대상·제외 인원, 수납액, 1인당 금액, 잔액
- 현황: 올해 대회, 레슨 가능 현황, 대시보드 요약

1인당 금액은 `(총액 - 후원금) / (대상인원 - 제외인원)`을 원 단위 올림합니다. 잔액은 `총액 - 후원금 - 수납액`입니다. 음수 잔액은 초과 수납을 뜻합니다. 회원·대회는 현재 이름을 복사하여 기록하므로 이름 변경이 기존 내역에 자동 반영되지 않습니다.

## 검증

```sh
npm test
```

테스트는 임시 데이터 디렉터리에 별도 서버를 실행하므로 운영 데이터를 변경하지 않습니다.

## 운영 범위

현재 버전은 로그인, 사용자별 권한, 실시간 메시지 전달, 결제 연동이 없는 기본형입니다. 모든 접속자가 같은 데이터를 편집할 수 있으므로 공개 인터넷에 직접 배포하지 말고 신뢰할 수 있는 내부 환경에서 사용하세요. 개인정보를 사용하는 실제 운영에는 인증·접근제어와 백업 정책을 추가해야 합니다.
