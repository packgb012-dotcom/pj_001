# 탁구센터

회원·회비·레슨·대회·소통·영업·정산과 대회 참가 신청을 관리하는 웹앱입니다. Node.js 24 이상이 필요하며 별도 런타임 패키지 설치는 필요 없습니다.

## Windows에서 시작하기

1. ZIP을 바탕화면 등에 압축 해제하고 `package.json`이 있는 폴더를 엽니다.
2. 파일 탐색기 주소 표시줄에 `cmd`를 입력하고 Enter를 누릅니다.
3. 아래 명령을 실행합니다.

```sh
npm start
```

4. 브라우저 주소창에 `http://localhost:3000`을 입력합니다.
5. 처음 실행할 때 **관리자 비밀번호**를 8자 이상으로 설정합니다. 기존 데이터는 유지됩니다. 비밀번호는 안전하게 별도 보관하세요.
6. 사용 중에는 명령창을 켜두고, 종료할 때는 Ctrl+C를 누릅니다.

기본 포트는 3000이며 `PORT`로 변경 가능합니다. 데이터는 `data/center.sqlite`에 저장되며 `DATA_DIR`로 저장 위치를 바꿀 수 있습니다. 백업은 서버를 중지한 뒤 `data` 폴더 전체를 복사하세요. 데이터 폴더에는 개인정보와 로그인 정보가 있으므로 GitHub에 올리거나 공개하지 마세요.

## 기존 버전에서 업데이트

1. 기존 서버 명령창에서 Ctrl+C를 눌러 종료합니다.
2. **기존 `data` 폴더 전체를 별도 위치에 백업합니다.**
3. GitHub에서 최신 ZIP을 내려받아 별도 폴더에 압축을 풉니다.
4. 백업한 `data` 폴더를 새 버전의 `package.json`과 같은 위치로 복사합니다. 다른 데이터 폴더와 무작정 합치지 마세요.
5. 새 폴더에서 `npm start`를 실행합니다. 추가 테이블은 자동 생성되며 기존 회원·대회는 유지됩니다.
6. 브라우저에서 새로고침하고, 처음 표시되는 관리자 비밀번호를 설정합니다. 이미 설정한 경우 기존 비밀번호로 로그인합니다.

서버 실행 중인 SQLite 파일을 복사하거나 삭제하지 마세요.

## 관리자 사용 순서

- **회원관리**: 회원의 이름·전화번호를 등록하고 `회원 로그인 비밀번호`를 8자 이상으로 설정합니다. 회원은 그 전화번호와 비밀번호로 로그인합니다. 비밀번호를 수정하지 않을 때는 빈칸으로 두면 됩니다. 비밀번호는 해시로 저장되며 기존 비밀번호 조회 기능은 없습니다. 비밀번호를 새로 설정하면 해당 회원의 기존 로그인 세션은 종료됩니다. 전화번호 중복 등록은 허용하지 않습니다.
- **대회·행사관리**: 일시(한국 시간), 장소, 자격, 정원, 안내사항을 입력합니다. 성인은 만 19세 이상 기준이며, 학생 대회는 회원의 `학생 여부`가 학생이어야 직접 신청할 수 있습니다.
- **대시보드**: 월별 캘린더에서 대회를 클릭하면 상세 정보와 신청자 명단을 확인합니다. 이전 달·다음 달·오늘 이동을 지원합니다. 관리자·회원 캘린더의 각 대회에는 `참가 3 / 20명`처럼 현재 참가 신청 인원과 정원을 표시합니다. 관리자 화면에서 `현황 새로고침`을 누르면 최신 신청 인원을 불러옵니다.
- **대시보드 요약 카드**: 전체 회원·이번 달 수납·진행 중인 레슨·다가오는 대회를 클릭하면 최신 현황을 불러와 상세 목록을 엽니다. 이번 달 수납은 한국 날짜 기준 해당 월의 납부완료 내역만 합산합니다. 다가오는 대회는 오늘을 포함하며, 목록에서 대회명을 클릭하면 대회 상세와 신청자 명단으로 이어집니다. 상세 창의 전체 보기 버튼으로 각 관리 화면에 이동합니다.
- **참가신청관리**: 회원을 대신해 신청을 등록하거나, 신청 회원·대회를 수정하고 신청을 취소합니다. 중복과 정원을 검사합니다. 관리자는 자격을 직접 확인하여 지난 대회와 자격 제한 대회도 대리 등록할 수 있습니다.
- 회원·대회를 삭제하면 해당 참가 신청도 함께 삭제됩니다. 취소 이력을 별도로 보관하는 기능은 없습니다.

## 회원 사용 순서

1. 브라우저에서 회원용 주소 `/member`를 엽니다. 같은 PC에서는 `http://localhost:3000/member`입니다.
2. 관리자에게 받은 전화번호와 비밀번호로 로그인합니다.
3. **전체 대회 → 상세 보기 → 참가 신청하기**를 선택합니다.
4. **내 신청 캘린더**에서 본인이 신청한 일정을 보고, 일정을 클릭해 상세 내용을 확인하거나 참가를 취소합니다.

대회 시작 전까지만 회원이 직접 신청·취소할 수 있습니다. 시작 후 변경은 관리자에게 요청하세요. 정원이 찼거나 자격이 맞지 않으면 신청할 수 없습니다. 로그인 세션은 8시간이며 본인의 신청만 표시됩니다. 관리자는 전체 신청자를 봅니다. 관리자와 회원 화면을 동시에 테스트하려면 다른 브라우저 또는 시크릿 창을 사용하세요.

회원별 개인정보 수정·비밀번호 자체 변경·회원 자가가입 기능은 아직 없으며 관리자가 처리합니다. 신청 상태는 화면을 새로고침하거나 탭을 전환하면 갱신됩니다.

## 다른 회원의 휴대폰에서 접속하려면

`localhost`는 각 기기 자신을 뜻합니다. 센터 PC 주소를 회원에게 전달해도 인터넷에서 자동 접속되지는 않습니다. 여러 회원이 외부에서 사용하려면 항상 실행되는 서버, HTTPS 도메인, 영구 저장소와 백업이 있는 환경에 배포해야 합니다. 공개 전에 **신뢰하는 PC에서 최초 관리자 비밀번호 설정을 완료**하세요. HTTPS 배포에서는 `COOKIE_SECURE=1`을 지정합니다. 현재 저장소에 코드를 올리는 것은 서버 배포와 다릅니다.

## 카카오톡·문자 대회 알림

현재 실제 카카오톡·문자 발송 기능은 연결되어 있지 않습니다. 아래 준비 후 발송업체 API와 연동하는 추가 작업이 필요합니다.

- **문자(SMS/LMS)**: 문자 발송업체 계정 생성, 센터 발신번호 인증, 발송 비용 충전 또는 결제 설정이 필요합니다.
- **카카오 알림톡**: 카카오 비즈니스 채널과 알림톡 지원 발송업체를 연결하고, 사용하려는 정보성 안내 템플릿의 심사·승인을 받아야 합니다. 대회 모집 홍보 등 광고성 내용은 알림톡으로 보낼 수 있는지 별도 확인하고 업체가 지원하는 적절한 채널을 사용해야 합니다.
- SOLAPI·알리고 등에서 카카오·문자 지원 범위, 사업자 요건과 비용을 확인한 뒤 업체 하나를 선택할 수 있습니다. 요건과 단가는 해당 업체의 최신 안내를 확인하세요.
- 연동 시 관리자가 대회와 수신 대상(전체/신청자 등)을 선택하고, 수신 인원·문구를 미리 확인한 후 발송하도록 구현하는 것이 좋습니다. 발송 결과·실패 사유·중복 방지와 필요 시 문자 대체 발송도 다룹니다.
- 회원의 수신 동의·연락처 관리와 광고성 메시지의 별도 동의·수신거부 처리가 필요합니다. API 키는 서버의 보안 설정으로 보관하고 채팅이나 GitHub에 올리지 않습니다.

## 나머지 기능

- 회비: 연·월회비, 레슨비, 참가비, 행사비, 물품비, 후원금 및 납부 상태
- 레슨: 코치, 월 횟수, 시간, 시작일, 단계, 완료·보충 횟수, 모집 가능 인원
- 소통: 관리자용 공지·메시지 게시 및 조회. 회원 간 실시간 채팅·카카오톡 연동은 아닙니다.
- 영업: 시간, 휴무일, 이용료
- 정산: `(총액 - 후원금) / (대상인원 - 제외인원)`을 원 단위 올림합니다. 잔액은 `총액 - 후원금 - 수납액`이며 음수는 초과 수납을 뜻합니다.
- 현황: 올해 대회와 레슨 가능 현황

회비·레슨·정산의 이름은 입력 시점의 이름을 복사한 기록입니다. 참가 신청은 회원·대회 ID로 연결되므로 이름 변경을 반영합니다.

## 검증

```sh
npm test
```

테스트는 임시 데이터 디렉터리와 별도 서버를 사용하여 기존 데이터를 변경하지 않습니다. 관리자·회원 접근 제어, 등록·수정·삭제, 대리 신청, 정원·중복 방지, 취소, 자격과 시점 제한, 데이터 보존, 캘린더 날짜 계산을 검사합니다.
